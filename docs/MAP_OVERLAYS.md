# 地图覆盖面板验收

客户端与服务端需要同时更新：`map_social` 是新增的双向数据包。共享名单与模式存于服务端玩家配置的 `map_module.position_blacklist_mode`、`position_allowed` 和 `position_blocked`。默认开启黑名单模式，兼容此前向所有人共享的位置行为；原 `share_position` 总开关仍优先生效。

每份名单最多 256 人，每人最多收到 32 条待处理请求；请求不跨开服持久化。玩家位置在服务端按接收者过滤，不能由客户端传入名单修改他人的共享规则。

由开发者构建后，连接实际服务端，以两名测试玩家核对：

1. 地图按钮、U、`/yzwc map waypoints` 打开覆盖列表；搜索、分类编辑、行操作可用，关闭后保留地图位置及缩放。覆盖层输入文字和滚动不能触发底图快捷键。
2. 普通点可分享坐标、编辑分类与私人描述；铅笔进入描述编辑，勾选保存。重新连接后描述保留，另一名玩家看不到它。
3. 玩家面板显示头像和名字，可搜索在线玩家、定位与追踪。共享名单、申请及拒收名单支持折叠，窄窗口通过滚轮查看后续条目。
4. A 关闭黑名单模式：未添加 B 时，B 收不到 A 的远程位置；添加后可见，移除后停止更新。请让双方相距足够远，不互相加载实体，以区分原版实体同步和地图位置共享。
5. B 请求查看 A 的位置，只有 A 收到请求；拒绝不授权，同意将 B 加入 A 的共享名单。拉黑后既不共享远程位置，也不再接收该玩家的申请。
6. 开启黑名单模式后仍不得向被拉黑玩家发送位置。关闭位置共享总开关后，任何其他玩家均收不到位置；隐身、旁观者及地图权限规则仍生效。
7. 移出拒收名单不自动加入白名单。服务器重启后名单与模式保留，待处理请求清空。

当前实现保留地图导入的独立工具页；路径点列表、分类编辑、新建和详情均在原地图内完成。
