# YZUI MD3 界面改造与验收说明

本次统一了模组独立界面、YZUI 容器、HUD、提示和 Jade 的视觉。布局参考 API 服务端前端的 MD3 风格，配色采用官网的薄荷绿系。原版屏幕保留原有布局，共用控件可随 YZUI 主题更新；HUD 的位置、排列和已有位置设置继续沿用。

## 外观入口与效果

在游戏中按 **Shift+F → 设置 → 界面外观**；也可以从 **ModMenu → YouzaiWorldCore 设置 → 视觉 → 界面外观** 进入。选择即时生效，并保存到本机 `yzwc/client/global_settings.json` 的 `core_module` 节。

| 选项 | 配置值 | 效果 |
| --- | --- | --- |
| 官网浅色（默认） | `yzui_theme: LIGHT` | 薄荷绿、奶油绿容器色，浅色表面与深绿文字 |
| 同色系深色 | `yzui_theme: DARK` | 深绿表面、浅薄荷色强调与浅色文字 |
| 标准卡片（默认） | `yzui_visual_style: STANDARD` | 半透明圆角卡片、轻度暗化背景、短促柔和过渡 |
| 半透明磨砂 | `yzui_visual_style: FROSTED` | 半透明卡片、更轻的背景遮罩、页面背景模糊与更明显的过渡 |
| 简洁低特效 | `yzui_visual_style: MINIMAL` | 半透明表面，关闭卡片阴影、背景模糊及界面过渡，保留即时悬停/焦点反馈 |

主要品牌色为 `#A8E6CF`、`#DCEDC1`、`#6BB39B`、`#345E54`。正文、次要文字、成功、警告、错误与信息提示分别使用可读的主题色。

磨砂页面使用 Minecraft 提供的背景模糊，强度受游戏的模糊设置影响；HUD 和 Jade 使用相应的半透明表面。已有动画范围设置继续生效，低特效预设会令实际动画模式为关闭，但保留用户原先的动画范围选择。

HUD 保留原有布局、位置、排列及用户透明度设置。大底板与槽位使用低不透明度，连续叠加底板、槽位和选中填充后仍保留至少四成背景透过。文字周围的紧凑底衬已从原先固定 90% 不透明度改为随预设使用 14%–18%，并继续乘以用户设置/淡出透明度；文字本身的透明度不因底衬调整而改变，通过贴合字形的轻微对比色阴影辅助阅读。冒险等级交叉淡入文字仍共用一块底衬，避免重复叠加。Jade 的文字颜色按半透明卡片在黑暗洞穴和白色雪地上的实际合成色校正，嵌套层与槽位不会重新变成实色。

只有弹窗保留前一窗口作为背景，嵌套弹窗按顺序保留父弹窗及其下面的页面。普通窗口直接使用场景背景：游戏外显示 Minecraft 标题页的原版旋转全景图，游戏内显示游戏画面，不叠加此前的设置、菜单或邮件等窗口。父层仅绘制，不重新初始化、重新拉取数据或接收输入；进入普通窗口、世界改变或关闭页面时清理旧背景层。背景遮罩固定于屏幕，不随卡片移动。邮件的玩家选择、附件选择与通用确认框均使用同一套模态过渡。

屏幕级弹窗通过 `YzuiPopupScreen` 声明，包括退出确认、强制更新、加入受限、配置导入成功及锚点命名。设置外壳仅在承载确认框或显卡警告时返回弹窗状态，普通设置和资源包等专用页面使用场景背景。返回与嵌套按窗口实例识别，因此同一个屏幕类可以同时承载普通页面和多层确认框；打开弹窗时父页面保持可见，关闭后返回实际父页面时不重复淡入。

页面进入/退出采用短距离位移、轻微缩放与淡入淡出，无回弹。`BASIC` 文案改为“模组页面”，`FULL` 改为“全部页面”；两种范围内的页面使用相同动效。返回父层时只让当前页面退出，父层不重复播放进入动画；快速打断进入动画时，从最后显示的帧开始退出。鼠标点击、滚动和拖拽使用同一帧的逆变换；淡出时拦截重复操作。按钮、输入框、选择控件与配方按钮增加轻微状态高亮，低特效保留即时反馈。

创造物品栏的玩家模型移至右上方独立区域，限制预览边界，并修正 Minecraft 26.2 实体预览不读取 GUI 矩阵造成的缩放偏移；与背包、装备、副手和搜索框分开。铁砧重命名字段取消底部黑线，使用圆角容器、主题色光标与悬停/焦点描边。

独立页面使用统一逻辑视口适应窗口和 GUI 缩放：一般页面至少 480×360，容器至少 380×280；邮件沿用 960×540 设计视口。鼠标位置、拖拽与提示位置使用对应的逆变换。较小窗口通过整体缩放保证操作区可达。

### Shift+F 排版与整图按钮修复（2026-09-12）

修复世界切换页以及登录、注册、注册邮箱、找回密码、账户管理中将 `setRectangle(width, height, x, y)` 的宽高和坐标传反的问题。主菜单和世界页共用 2:1 图片网格，按视口约束宽高并居中末行；标题、返回与关闭保留独立空间。邮件角标收进按钮内，关于我的模型单独裁剪，冒险页压紧底部间距并限制长等级数字的宽度，设置列表居中。

菜单复用已创建的控件，恢复平滑悬停、原版提示入口与焦点朗读；点数和等级变化仍刷新加点状态。分区切换依次淡出、淡入，避免前后两页文字和模型同时叠画；模型、文字和图片共同应用过渡透明度，关闭动画时立即切换。

导航按钮用整张 PNG 覆盖，不叠加名称文字；保留多语言悬停提示和鼠标/键盘操作。主菜单 12 张、世界入口 10 张统一建议 512×256 PNG。圆角、悬停、焦点和禁用状态由程序绘制，不需额外状态图。旧方图或竖图暂按比例居中裁切，新图由用户重绘后覆盖。完整文件名、主体元素、配色、安全区和本轮文件清单见 [YZUI_MENU_ARTWORK.md](YZUI_MENU_ARTWORK.md)。

## Jade 首次启动崩溃修复

2026-09-12 的崩溃发生在首个客户端 tick，首次资源加载尚未结束。桥接代码在检查主题是否可用之前调用了 `overlay.getTheme()`；Jade 此方法会触发懒初始化，而它需要的默认主题此时为空，导致 `ThemeHelper.getTheme()` 抛出空指针。

`JadeThemeBridge.tick()` 现在先用不会触发初始化的 `hasTheme(JadeIds.DEFAULT_THEME)` 检查默认主题是否就绪，再读取或应用主题。等待期间不修改桥接状态或保存配置，适用于 YZUI 开启、关闭和资源重载过程。

新增回归脚本编译实际 `JadeThemeBridge.java` 与两种外观枚举，仅替换 Minecraft/Jade/config 等外部依赖来模拟加载顺序。修复前源码对照能重现上述空指针，修复后全部场景通过；实际 Jade 26.2.11 API 已核对，并通过 Gradle 编译。游戏中的启动与 F3+T 重载仍需按下表验收。

建议每组主要页面覆盖以下组合：

- **6 种外观组合**：LIGHT/DARK × STANDARD/FROSTED/MINIMAL；另测已有动画范围的关闭、基础与完整模式。
- **窗口与 GUI 缩放**：854×480、1280×720、1920×1080、窄窗口/超宽窗口；GUI 缩放 1、2、4 和自动，并在页面打开时调整大小。
- **输入边界**：鼠标与键盘、长中英文文本、空列表、较多列表项、长物品描述、打开弹窗时输入、在过渡期间点击；确认渲染位置与命中区域一致。
- **动效和反馈**：快速开关页面、进入未结束就返回、连续 Escape、动画中滚动/拖拽；悬停按钮、输入框、复选框、下拉菜单、滑块与配方控件；低特效不播放页面过渡，但仍显示状态反馈。
- **HUD 保存**：先记录位置和透明度，修改位置后切换所有外观，再重新打开游戏确认设置保留。
- **HUD 文字底衬**：在浅/深色及三种预设中查看生命、饥饿、魔力、冒险等级、装备、状态效果、计分板和拾取提示；文字周围矩形应明显透景，文字保持原透明度；降低 HUD 透明度或等待飘字淡出时，底衬与字形阴影一起淡出。
