# YZUI 工作方块界面

附魔台、织布机、制图台、切石机和砂轮使用与已有工作方块一致的主题卡片、物品标题图标、强调线和悬停槽位。右上角使用全屏地图同款的 14×14 关闭按钮，支持提示、键盘激活及原版容器关闭流程。酿造台沿用现有界面。

标题栏在原版内容区上方增加 20 像素，保留原版 176×166 内容区和所有槽位、选项、滚动条的坐标。标题空白处属于面板内部，持物点击不会误触界面外丢弃。配方与图案格保留选中、悬停和禁用状态；加号及操作箭头使用几何图标。明暗主题和视觉预设共用当前 YZUI 配色。

五种屏幕继承对应的原版屏幕，继续执行书本动画、旗帜图案、地图预览、菜单监听器和服务器交互。主题 Mixin 仅作用于这些 YZUI 子类；关闭 YZUI 后再次打开方块会使用原版界面。

## 离线检查

在仓库根目录执行：

```sh
python tools/verify_yzui_workstations.py --java-home /path/to/jdk-25
git diff --check
```

工具使用本地 `minecraft_jar/<版本>/<版本>.jar` 和 `javap`，检查四个 Mixin 的注册、七个包装方法的参数与返回类型、十九处真实方法内的注入调用、原版构造签名、屏幕路由和资源引用。不编译、下载或启动游戏，也不执行 Mixin 变换。

包装 `super` 调用时，MixinExtras 要求接收者是当前被注入的具体屏幕。共用注入的 `AbstractContainerScreen<?>` 参数使用 `@Coerce` 兼容五种屏幕；检查工具按真实调用指令和类继承关系核验，并测试缺失标记及传入无关类型的回归情况。

## 游戏内验收

按仓库约定，由开发者构建后连接测试服务端验收：

| 界面 | 操作与预期 |
| --- | --- |
| 附魔台 | 放入可附魔物品与材料，检查书本动画、三行选项、等级要求和提示；材料或经验不足时禁用，附魔后按原版消耗与更新。 |
| 织布机 | 放入旗帜与染料，选择图案并滚动超过一页；检查选中状态、旗帜预览及产物；图案物品和图案达到上限时保留原版行为。 |
| 制图台 | 分别使用纸、空地图和玻璃板，检查扩图、两张复制地图的重叠层次及锁定标识；不可扩展、最大比例或已锁定地图保留原版错误提示。 |
| 切石机 | 使用拥有超过十二项配方的输入，检查滚轮及拖动滚动条、选中边框、物品提示、结果取出与快捷移动。 |
| 砂轮 | 检查修复、去附魔、诅咒保留、经验返还以及无效输入的错误标识。 |

每种界面还需检查：普通点击、Shift 移动和槽位拖拽；右上角关闭、Esc 关闭、持物关闭；持物点击标题空白处；缩放及窄窗口中的按钮命中；明暗主题与不同视觉预设的文字对比；关闭 YZUI 后原版界面正常。
