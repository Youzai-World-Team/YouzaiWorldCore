# YZUI 暂停屏幕

进入游戏后按 Esc 打开。开启 YZUI 时，暂停屏幕使用与游戏菜单一致的薄荷绿 MD3 配色、单层半透明圆角卡片和线性图标，实时读取现有浅色／深色主题与标准／磨砂／低特效预设。

操作区突出「回到游戏」，下方提供进度、统计、选项、账户管理及退出。账户管理替换原世界选项，与选项并排；只有一个账户入口。宽屏右侧显示当前玩家、服务器名称或单人世界、跟随鼠标转动的玩家模型。窄屏或低矮窗口隐藏模型卡片，退出保持最后一行。320×180 GUI 单位仍可访问全部按钮，不缩小正常字号。

表面不透明度为标准／低特效 74%、磨砂 70%，背景遮罩仅 12/255，所有预设均不模糊游戏画面。返回按钮使用实色主操作，退出使用轻微警示底色。普通、悬停和焦点状态的文字均按半透明表面校正对比度。

页面取消暂停状态句子，标题下方直接显示操作。图标统一使用 12×12 正方形尺寸，横纵等比缩放并垂直居中；退出使用门与箭头图标，与返回箭头区分。

## 行为

- 保留入口的原版按钮实例、退出回调和 `disconnectButton` 字段继续使用；未提交举报草稿图标、音乐提示和延迟字幕保留。世界选项从输入、渲染与朗读三份列表同时移除。
- Esc、Tab／Shift+Tab、回车和空格沿用原版输入。方向键优先移动到相邻行，跳过禁用入口；实际屏幕焦点与控件焦点同步。重建窗口或从设置返回后恢复上一入口。
- 账户管理返回实际暂停屏幕；开发者单人测试玩家仍隐藏账户入口。
- 关闭 YZUI 后沿用紧凑暂停菜单与玩家模型，账户管理同样替换世界选项。`showPauseMenu=false` 的纯暂停标题屏不创建卡片或账户按钮。
- 没有新增配置、网络包或服务端数据。新文案同步至十种语言。

## 验证

```sh
python3 -B tools/verify_yzui_pause.py --java-home /path/to/jdk-25
python3 -B tools/verify_yzui_menu.py --java-home /path/to/jdk-25
git -c core.safecrlf=false diff --check
```

暂停回归直接运行实际菜单、按钮装饰、焦点与布局 Java 源码，仅以替身隔离 Minecraft 绘制与账户页面。检查 10 种窗口尺寸、按钮身份和回调、三份控件列表、账户位置与返回、状态提示移除、模型裁剪、焦点恢复及六种外观下的文字对比度。图标检查覆盖正方形边界、横纵等比缩放、矩阵恢复和退出图标。语言检查拒绝重复键，并检查全部文案。

未执行 Gradle 构建、打包或游戏启动。上述检查不能替代实际客户端的 GPU 绘制和运行时 Mixin 验收。游戏中应检查浅色／深色 × 三种预设、不同 GUI 比例下的图标比例、鼠标和键盘操作、设置返回、退出世界以及 YZUI 关闭后的菜单；账户流程在测试服务器验收。
