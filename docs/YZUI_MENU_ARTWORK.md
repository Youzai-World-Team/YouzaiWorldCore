# Shift+F 菜单按钮绘图规范

主菜单与世界切换页已改为「一张图片覆盖整个按钮」，不再叠加名称文字。名称保留在多语言悬停提示与键盘朗读中，邮件未读角标继续显示。美术图片由你重绘，本轮不替换现有 PNG。

## 导出规范

- **22 张图全部为 2:1 横向，建议 512×256 像素、PNG RGBA、sRGB。**
- 源稿建议 1024×512 或更大同比例尺寸，再缩小导出；代码也支持直接使用 1024×512。
- 覆盖 `src/main/resources/assets/youzaiworldcore/textures/gui/` 内的同名文件。
- 画满整个画布，不放外部留白。圆角裁切、悬停高亮、焦点框、禁用与淡出由程序处理，不需要另画状态图、固定圆角或阴影。
- 关键图形距四边至少 32 像素；缩小至约 112×56 后也应容易辨认。
- `mail.png` 右上角约 **160×112 像素**留给未读角标，主体偏左。
- 建议背景像素为 80%–88% 不透明，主体 95%–100%；透明处显示下方的主题卡片。
- 推荐图内不写字，以便兼容多语言；如要艺术字，请绘入图片。程序不会额外叠字。
- 浅色/深色共用一张图，不反相颜色；不需要额外的 hover/pressed/disabled、深色或动画帧图片。

新图只裁去圆角，不额外裁切或拉伸。旧图包含方图、竖图，目前临时按 2:1 **等比居中裁切**，边缘可能不可见；替换为新比例后整张显示。

## 配色和画风

品牌主色：薄荷绿 `#A8E6CF`、奶油绿 `#DCEDC1`；主体中间色用灰绿 `#6BB39B`，轮廓和深色细节用深绿 `#345E54`，可配暖白 `#F4F8EF`。

小面积强调可用淡金 `#E6CF91`、灰蓝 `#8DBBC1`、淡紫 `#B1A0CA`；下界、警示元素用低饱和陶红 `#CA8B78`。避免整张高饱和红色或纯黑。

推荐柔和扁平或轻立体插画、大色块、清晰轮廓。主体约占画面一半到三分之二，两侧用简化场景延展；全套保持光源、透视、线条粗细一致，避免小字、密集纹理和细碎线条。每张图要有可辨认的主体，不能只靠颜色区分入口。

## 本轮修复

- 世界切换网格原先将 `setRectangle(width, height, x, y)` 的宽高与坐标传反；现已共用固定比例网格。账户管理、登录、注册、注册邮箱、找回密码的同类 40 处调用也已纠正。
- 主菜单/世界页共用内容边界；返回、标题、关闭各自留出位置；邮件角标收进对应按钮。
- 关于我的模型增加局部裁剪；冒险页调整底部间距，长等级数字在预留宽度内缩放；设置列表在内容区居中。
- 控件仅在首次显示或视口变化时创建，悬停和焦点不再每帧重置；加点可用状态仍随等级和点数即时更新。
- 分区依次淡出、淡入，模型和文本共同过渡，避免同时叠画两页；过渡中拦截输入，关闭动画时立即切换。
