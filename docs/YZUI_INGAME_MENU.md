# Shift+F 游戏菜单与账户页面

主菜单、世界选择、玩家资料、账户管理、登录、注册、邮箱验证、密码重置、称号与邮件页面使用通透的薄荷绿 MD3 样式。继续读取 YZUI 的明暗主题和效果预设。

## 外观

- 主菜单与世界入口采用圆角卡片、几何线性图标和本地化文字。22 个入口沿用十种语言的现有翻译；旧图片资源保留，但这两个菜单不再依赖图片内的文字。
- 主菜单拆分标题栏与内容，移除覆盖整个窗口的大底板。表单使用统一账户标题、单层半透明卡片、圆角输入框和明确的主操作。
- 标准／低特效卡片不透明度为 74%，磨砂预设为 70%。菜单不叠加阴影，背景遮罩仅为 12/255；所有预设都保留清晰的游戏画面，不调用整屏背景模糊。
- 文字根据表面颜色和最不利的世界背景校正；悬停／键盘焦点造成的卡片底色变化也参与校正。
- 标题页、原版设置和容器界面继续使用各自现有外观。游戏内的独立外观设置页沿用这套通透表面。

## 关闭与返回

| 页面／状态 | Esc | 关闭按钮 |
| --- | --- | --- |
| 主菜单首页 | 先收起弹窗／下拉框；无浮层时回到游戏 | 右上角 × 回到游戏 |
| 世界选择、玩家信息、冒险等级、更多 | 先收起弹窗／下拉框，再返回上一层；前进动画中取消前进，返回动画中完成返回 | 右上角 × 回到游戏 |
| 账户管理空闲状态 | 先收起弹窗；表单回到账户首页，账户首页回到父菜单 | 右上角 × 回到游戏 |
| 账户请求处理中、必须确认的操作完成状态 | 保留原有流程，不能关闭 | 隐藏 |
| 登录、注册、注册邮箱验证 | 不能关闭 | 不显示 |
| 登录前重置密码 | 保留原有返回登录流程，不能退出认证进入游戏 | 不显示 |
| 称号、收件箱、已发送邮件 | 返回实际父页面；列表保留选择和滚动位置 | 右上角 × 回到游戏 |
| 邮件编辑 | 先关闭选择器／下拉框；已修改时询问放弃修改或继续编辑 | × 也经过丢弃确认，确认后回到游戏 |
| 游戏内外观页 | 沿用该页现有行为 | 沿用该页现有行为 |

`YzuiMenuScreen` 统一关闭权限，Esc 委托当前页的 `onClose()` 逐层返回，× 调用 `closeMenu()` 明确退出。`GuiAnimationController.setScreenImmediately` 清除待提交的切页目标，防止旧页面在下一帧重新打开。认证关闭限制继续生效。

## 常用入口与操作反馈

方向键按卡片实际位置移动焦点，跳过禁用和隐藏入口；Tab / Shift+Tab 和回车继续可用。返回父菜单、退出专用页面及调整窗口后恢复原入口焦点。直接打开子页时，返回按钮与 Esc 使用相同的返回逻辑。

首页按任务分为两组：「常用操作」直接进入切换世界、邮件、地图；「我的信息」进入玩家资料、冒险等级、称号。卡片同时显示待领取邮件数、等级与可用技能点、当前称号或用途提示。网站等低频入口归入「更多」，底部直接提供宠物、路径点、设置和更多入口。暂未实现功能的回调和 Shift+F 设置页内容不变。

世界页进入时向服务端请求公开世界目录，显示实际世界名称、当前世界和游戏模式；当前所在或未配置的池不可重复选择。确认框说明目标模式、背包与经验独立保存、进入位置按历史记录或出生点确定。确认后禁用重复请求，收到匹配的成功结果才退出；失败原因保留在页内。目录加载和切换结果等待均有 15 秒提示，切换超时不自动重试。重新进入后旧响应不影响新页，调整窗口保留正在等待的请求。

邮件编辑的退出确认比较正文、收件范围、附件内容和勾选状态，物品按内容比较。继续编辑保留输入；丢弃后才发送一次取消编辑包并返回原父页面。调整窗口保留附件输入及勾选状态。编辑页的「存草稿」会把收件范围、正文、物品附件、指令、数值和勾选状态保存到本机，并返回父页；再次打开时可用「恢复」取回。草稿按服务器、玩家与编辑邮件 ID 隔离，写入 `yzwc/client/global_settings.json` 的 `mail_module`。恢复前会确认替换当前表单，发布请求发出后仍保留已存草稿，丢弃确认会删除当前草稿。

邮件界面保留正常 GUI 字号，按当前可用宽高排版；只有小于 320×240 GUI 单位的极端窗口会缩放。窄屏或低矮窗口一次显示收件列表或详情，Esc／列表按钮先返回列表并保留选择与滚动位置。正文与附件可滚动查看，操作按钮固定在详情底部。已发送邮件在窄屏改为卡片列表；编辑表单在窄屏将主题、物品槽和经验附件分行，正文与表单分别滚动，顶部操作区保持可见。

冒险属性「＋」先显示消耗 1 技能点及当前／加点后加成，再提交请求。提交期间禁止重复加点，服务端返回成功或失败后恢复操作；15 秒超时会提示先核对当前属性。抗性达到 40 点（80% 减伤）后停止消耗技能点，服务端同样校验属性键与上限。

宠物页读取自己的宠物列表，选择后可以切换陪伴、狩猎、攻击、守卫模式，改名或高亮；操作复用原命令树的权限和实体校验，结果返回后刷新列表。地图底部为设置、路径点、玩家、雷达、维度图标＋文字按钮，上方图标、下方文字，窄屏自动换行，首页路径点入口直接打开地图内路径点列表。

邮件发布、已发送列表和编辑加载只在玩家仍停留于发起页面及同一连接时触发切页。后台列表响应只更新缓存，重复或迟到的预填不会覆盖正在编辑的表单；离开后的可编辑预填会发送取消编辑请求，恢复服务端暂时隐藏的邮件。等待时防止重复请求，15 秒后提示超时，命令入口仍可从游戏打开邮件页面。

新增 `world_pool_menu_request`（C2S）、`world_pool_menu_state` 与 `world_pool_teleport_result`（S2C），客户端与服务端需同时更新；旧的 `world_pool_teleport` 保留。新增界面文案同步至十种语言。

## 本地登录／注册预览

开启客户端开发者模式后，从标题页进入 **YouzaiWorldCore 测试… → 登录页面预览／注册页面预览**。测试选择页另保留“进入测试环境”，仍按原配置打开单人世界选择或连接测试服务器。

两个预览复用实际的 `LoginScreen`／`RegisterScreen`，页面底部显示“本地预览 · 不发送请求”。输入校验、错误提示、焦点、窗口缩放与主题效果均可查看。提交仅弹出本地反馈；“忘记密码”也只显示本地反馈，不进入真实找回流程；“断开连接”仅返回测试页。

预览支持右上角 × 和 Esc 立即返回测试页，包括错误提示及页面过渡期间。模式由预览实例单独保存，调整窗口后仍然有效。正式认证的默认构造路径没有预览标记，继续禁止关闭并发送正常认证请求。

## 客户端验收

1. 进入服务器后按 Shift+F，在浅色／深色 × 标准／磨砂／低特效六种组合中查看主菜单、世界选择、我的账户、冒险等级、称号与邮件。雪地、夜晚和室内背景应可见，文字清晰。
2. 从首页进入世界页、玩家信息和冒险等级，确认 Esc 每次返回一层；弹窗和下拉框优先关闭。前进动画中按 Esc 取消前进，返回动画中按 Esc 完成返回，× 始终退出到游戏且下一帧不重新打开。
3. 检查登录、注册、邮箱验证、密码重置的输入、焦点、提示与主操作；受限流程没有关闭按钮，也不能通过 Esc 直接进入游戏。
4. 账户表单按 Esc 回到账户首页，再按 Esc 回父页；发起账户请求后确认关闭按钮隐藏。必须重新登录的完成提示不能跳过。
5. 打开邮件选择器后按 Esc 仅关闭选择器；编辑正文／附件后退出，确认「继续编辑」保留输入、「放弃修改」返回父页，× 经确认后回到游戏。管理员取消编辑请求仅发送一次，调整窗口不清空输入或勾选。
6. 调整窗口与 GUI 比例，检查 320×180 到宽屏的缩放、输入框、长标题、验证码倒计时和右上角按钮。页面调整大小后已输入的内容应保留。
7. 使用同版本客户端和服务端检查当前世界、游戏模式、未配置池、确认取消、成功和失败反馈。等待期间调整窗口或返回重开，确认不会重复请求或被旧响应关闭。目录与传送结果超时应显示对应提示。
8. 从首页打开地图、称号、邮件再返回，确认回到原页面，邮件列表选中项与滚动位置保留。

回归脚本原先被 `*.py` 规则忽略，现为上述五份脚本添加了 `.gitignore` 例外，便于随改动保留验证方法。

下一轮游戏验收：用方向键在首页卡片间移动，打开并返回玩家资料/地图/邮件后确认焦点回到原入口；等待邮件加载时退出、重开其他页面或编辑正文，确认迟到响应不强制切页。离开的编辑请求返回后，服务端邮件应恢复可见。

本轮游戏验收补充：在 320×240、480×360 和 960×540 GUI 视口检查邮件列表、详情、已发送与编辑；长正文和附件应可滚动，滚动后顶部按钮仍可用。保存包含未勾选附件输入的草稿，退出客户端后重开恢复，并在不同服务器和账号确认隔离。用有限技能点确认加点成功／拒绝／超时反馈，在 40 点抗性时检查客户端与服务端均阻止继续消耗。宠物页检查无宠物、权限拒绝、宠物未加载、改名和四种模式，并确认返回首页。
