# Shift+F 游戏菜单与账户页面

主菜单、世界选择、玩家资料、账户管理、登录、注册、邮箱验证、密码重置、称号与邮件页面使用通透的薄荷绿 MD3 样式。继续读取 YZUI 的明暗主题和效果预设。

## 外观

- 主菜单与世界入口采用圆角卡片、几何线性图标和本地化文字。22 个入口沿用十种语言的现有翻译；旧图片资源保留，但这两个菜单不再依赖图片内的文字。
- 主菜单拆分标题栏与内容，移除覆盖整个窗口的大底板。表单使用统一账户标题、单层半透明卡片、圆角输入框和明确的主操作。
- 标准／低特效卡片不透明度为 74%，磨砂预设为 70%。菜单不叠加阴影，背景遮罩仅为 12/255；所有预设都保留清晰的游戏画面，不调用整屏背景模糊。
- 文字根据表面颜色和最不利的世界背景校正；悬停／键盘焦点造成的卡片底色变化也参与校正。
- 标题页、原版设置和容器界面继续使用各自现有外观。游戏内的独立外观设置页沿用这套通透表面。

## 关闭与返回

| 页面／状态 | Esc | 关闭按钮 |
| --- | --- | --- |
| 主菜单及内部分类 | 立即回到游戏，包括打开下拉框、确认框和切页动画期间 | 右上角 × |
| 账户管理空闲状态 | 立即回到游戏 | 右上角 ×；底部返回仍回到父菜单 |
| 账户请求处理中、必须确认的操作完成状态 | 保留原有流程，不能关闭 | 隐藏 |
| 登录、注册、注册邮箱验证 | 不能关闭 | 不显示 |
| 登录前重置密码 | 保留原有返回登录流程，不能退出认证进入游戏 | 不显示 |
| 称号、邮件、游戏内外观页 | 立即回到游戏 | 右上角关闭；返回操作独立保留 |

`YzuiMenuScreen` 统一关闭权限。键盘入口先处理可关闭菜单的 Esc，再判断动画是否阻止输入。`GuiAnimationController.setScreenImmediately` 清除待提交的切页目标并立即关闭，防止旧页面在下一帧重新打开。编辑邮件时保留原有取消编辑数据包，避免遗留服务端编辑会话。

## 本地登录／注册预览

开启客户端开发者模式后，从标题页进入 **YouzaiWorldCore 测试… → 登录页面预览／注册页面预览**。测试选择页另保留“进入测试环境”，仍按原配置打开单人世界选择或连接测试服务器。

两个预览复用实际的 `LoginScreen`／`RegisterScreen`，页面底部显示“本地预览 · 不发送请求”。输入校验、错误提示、焦点、窗口缩放与主题效果均可查看。提交仅弹出本地反馈；“忘记密码”也只显示本地反馈，不进入真实找回流程；“断开连接”仅返回测试页。

预览支持右上角 × 和 Esc 立即返回测试页，包括错误提示及页面过渡期间。模式由预览实例单独保存，调整窗口后仍然有效。正式认证的默认构造路径没有预览标记，继续禁止关闭并发送正常认证请求。

## 自动验证

在模组目录执行（需要 JDK 25；可省略 `--java-home` 使用 PATH）：

```sh
python3 -B tools/verify_yzui_menu.py --java-home /path/to/jdk-25
python3 -B tools/verify_yzui_transitions.py --java-home /path/to/jdk-25
python3 -B tools/verify_auth_preview.py --java-home /path/to/jdk-25
```

本次检查通过：

- 菜单检查覆盖 60 组页面／窗口组合、五类账户表单的实际排版和关闭权限、22 个导航入口的十种翻译、七个维度池的原有请求映射、控件复用、图标与文字绘制、受限关闭按钮以及明暗主题的文字对比度。
- 页面生命周期检查通过 72 项断言，包含实际动画控制器的待提交切页取消、下一帧不重新打开、锁定页面拒绝关闭，以及所有效果预设下不模糊游戏画面。
- 使用本地 Minecraft 26.2 jar 的字节码核对了 `Screen`、`Gui.setScreen`、键盘事件与控件定位接口。
- 账户预览检查通过 45 项断言：直接执行真实登录／注册页面和测试选择页，模拟已有玩家连接，检查初始化、提交、发送边界、忘记密码与断开按钮都不会产生网络副作用；同时检查本地反馈、调整窗口保留输入、Esc／关闭按钮返回，以及正式认证仍按原路径发包。十种语言各补齐六个预览文案。

脚本使用原版客户端与绘制替身；表单检查提取实际布局和关闭方法运行。未执行 Gradle 模组编译、打包、游戏启动或服务端联调，上述检查不能替代实际客户端的 GPU、输入和网络验收。

## 客户端验收

1. 进入服务器后按 Shift+F，在浅色／深色 × 标准／磨砂／低特效六种组合中查看主菜单、世界选择、我的账户、冒险等级、称号与邮件。雪地、夜晚和室内背景应可见，文字清晰。
2. 在主菜单切页、传送确认、下拉框及进入／退出动画期间按 Esc；应立即回到游戏，随后也不重新弹回页面。点击右上角关闭与明确的返回操作，检查去向。
3. 检查登录、注册、邮箱验证、密码重置的输入、焦点、提示与主操作；受限流程没有关闭按钮，也不能通过 Esc 直接进入游戏。
4. 在账户管理的各子页关闭菜单；发起账户请求后确认关闭按钮隐藏，响应后按原有状态恢复。必须重新登录的完成提示不能跳过。
5. 在邮件编辑器中打开选择器后按 Esc，确认直接回到游戏；管理员编辑邮件后关闭，确认服务器收到取消编辑请求且仅发送一次。
6. 调整窗口与 GUI 比例，检查 320×180 到宽屏的缩放、输入框、长标题、验证码倒计时和右上角按钮。页面调整大小后已输入的内容应保留。

回归脚本原先被 `*.py` 规则忽略，现为上述三份脚本添加了 `.gitignore` 例外，便于随改动保留验证方法。
